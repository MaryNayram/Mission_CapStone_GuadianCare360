GuardianCare360

GuardianCare360 is a secure, role-aware task and notification system built for teams that need clarity, accountability, and speed. Designed for admins and employees, it streamlines task workflows, tracks progress, and keeps everyone informed — all from a clean, intuitive dashboard.

 Core Features

- Role Management  
  Two distinct roles: Admin and Employee — each with tailored access and controls.

- Task Control  
  Create, assign, update, and delete tasks with full visibility across status and deadlines.

- Smart Filtering
  Sort tasks by priority, status, and due date to stay focused on what matters.

- Secure Login  
  Role-based authentication ensures only the right users see the right data.

- Real-Time Notifications
  Users get alerts for new tasks, updates, and system-wide broadcasts.

- Deadline Tracking 
  Highlights overdue tasks and upcoming deadlines to keep teams on track.

-Broadcast + Personal Alerts
  Supports both global announcements and user-specific task updates.


Tech Stack

- PHP 7.4+
- MySQL 5.7+
- Bootstrap + Font Awesome
- XAMPP (Apache, PHP, MySQL)


 Built For

- Admins managing distributed teams  
- Employees tracking assignments and updates  
- Organizations needing secure, scalable task workflows



 System Highlights

- Modular backend: Models, DB, Auth, Notifications  
- Dynamic dashboard with real-time badge updates  
- Filterable notification center with pagination  
- Mark-as-read logic for personal alerts  
- Clean UI with responsive layout and role-aware navigation
